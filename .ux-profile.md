# UX Profile

All UI/UX skills in this project read this file before changing layout, copy, or interaction.

## Aesthetic reference

- **Standard:** Custom — Notion/Linear restraint on warm paper
- **Notes:** Warm off-white canvas, ink text, one vermilion accent (map-pin color, ties to the meeting-place theme). Pretendard for all UI text; monospace only for handles, times and numbers. Radius 6px (8px for large panels). No decorative illustration.

## Banned anti-aesthetics

- Purple/indigo/pink gradients anywhere, gradient text, rainbow CTAs
- Glassmorphism / `backdrop-filter`
- Emoji as UI icons, sparkles, rockets, "✨ AI-powered" style copy
- Icons in colored circles/squares as feature decoration
- Pastel pill wrappers on static metadata (tags are plain text unless they are filters)
- Cartoon people / stock illustration in empty states
- Hero blobs, floating shapes, glow shadows, testimonials with fake names

## Accessibility target

- **Level:** WCAG 2.1 AA
- **Contrast:** 4.5:1 body text, 3:1 large text and UI boundaries
- **Touch / focus:** 44×44px hit targets; 2px accent focus ring with 2px offset

## Brand tone and microcopy voice

- **Voice:** Utilitarian, warm — 해요체, short sentences, no exclamation marks in UI
- **Capitalization:** Sentence case for any English UI copy
- **Notes:** CTA는 "목적어 + 동사" (모임 만들기, 변경사항 저장). 확인/제출/OK 금지. 오류는 사용자를 탓하지 않고 다음 행동을 알려준다.

## Icon library

- **Library:** Lucide
- **Package / path:** `lucide-react`
- **Notes:** 16px inline, 20px in icon buttons, stroke 1.75

## Agent rules

1. Read this profile before creating or editing any UI, CSS, or microcopy.
2. New page → `page-patterns` (name the pattern before markup); layout / chrome → `viewports`; forms → `forms`; overlays → `surfaces`; loaders → `loaders`; empty views → `empty-states`; motion → `motion`. Before finishing UI, run `ux-audit`.
3. Use only Lucide icons. No emoji as UI icons.
4. Never introduce items on the banned list.
5. Destructive actions always use an explicit, named confirmation dialog.
